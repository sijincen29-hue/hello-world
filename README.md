# 苔苔小院

一个可以观察两位小动物居民的 3D 小院。当前布局让厨房、客厅、书房和电脑角共享连贯的木地板与通道，用早餐台、沙发和书架区分活动；卧室、浴室留有适度遮挡。院中有菜地、树木和围栏。米米与栗栗保持简洁圆润的造型与预设活动；点击居民卡片可近看造型。光线按钮可以依次切换午后、黄昏和灯火夜晚。尚未接入 AI。
