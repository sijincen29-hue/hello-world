# 苔苔小院

屋顶开放式 3D 微缩小屋，采用两排三间布局：后排是卧室、厕所和厨房，前排是电脑房、书房和客厅。院子保留菜地、树木、围栏、小兔米米和小熊栗栗。居民保留原先柔和、简洁的圆润比例，增加细小的眼部高光、袖口和尾巴，并以轻微转头、摆手和迈步表现活动。两位居民有各自的预设作息，会沿房间门口移动；卡片实时显示位置与活动，点击卡片可用固定斜上方角度近看造型，「全景」恢复完整场景。「暂停生活」会暂停作息。当前行为由规则驱动，尚未接入 AI。

## 文件

- `index.html`：页面结构、居民活动卡片和按钮；引用静态资源时带版本号以避免浏览器沿用旧场景。
- `style.css`：颜色、排版和手机布局。
- `world-data.js`：六间房的位置与颜色、通行路线、两位居民的活动计划。调整布局或作息优先改这里。
- `scene.js`：相机、光线、按房间组织的家具、三维居民与作息动画。它从 jsDelivr 加载 Three.js 0.170.0。

这是网页静态文件目录。可通过 HTTP 静态服务器预览；直接双击 HTML 可能因浏览器 ES 模块限制而无法显示场景。
